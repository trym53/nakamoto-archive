# Satoshi Nakamoto on the Cryptography mailing list

Total: 40 messages in 2 threads (18 of them from Satoshi Nakamoto)
Source: `src/cryptography-mailing-list-2008-October.txt.gz`, `-2008-November.txt.gz`, `-2009-January.txt.gz`

Complete threads are included, not just Satoshi's own posts, so that the
questions and replies he was responding to are preserved.

Each `Date` is reproduced exactly as the archive prints it, with its own offset.

> 1 of these messages carry `-0000`, which in mail headers means the
> timezone is *unknown* rather than UTC. Those are marked *(timezone not specified in source)*.

> and the v0.1 release (2009-01-08). Addresses appear obfuscated (`x at y.com`)
> as in the original pipermail archive.
